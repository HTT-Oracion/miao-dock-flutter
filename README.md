# miao-dock-flutter

基于 miao-dock 的 flutter 版本

## 目标：
### 1. 漫画翻译功能：
- 服务：桌面端实现 mangasvc + engine(manga-image-translator) + LLM(本地Sakura-GalTransl-7B-v3.7 or LLM API) , 支持单独部署、启动漫画图片翻译流水线；移动端采用量化版引擎、模型或通过局域网访问服务
- 功能：队列、投放、书架
  
### 2. 音乐模块：
- 支持平台：网易云、酷狗、QQ音乐、咪咕 + 本地
- 功能：所有通用播放功能、播放历史、歌词等

### 3. 番剧模块：待定
- 追番周表、排行榜等
