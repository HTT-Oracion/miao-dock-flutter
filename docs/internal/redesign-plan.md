### 1.3 动效层（参数唯一事实源 = `manga-viewer/motion.html`）

- 档位：快 150ms / 标准 300ms / 形变 320ms / 抽屉 380ms / 强调 500ms；曲线主力 `Curves.easeOutCubic`，结构变化（宽高/圆角/位置）用项目形变曲线 `Cubic(0.22, 0.61, 0.36, 1)`，纯透明度用 `Curves.easeOut`。
- **依赖提案（须拍板）**：引入 `flutter_animate`（纯 Dart、无平台通道、不触及 KGP 台账问题），effect 与设计稿 CSS 类 1:1（`fadeIn/slideY/scale/blur/shake/shimmer/crossfade` + `then()` 编排三段式 OSD）。不引入则用隐式动画手搓同参数（工作量 +2 天，效果等价）——**默认按引入准备**。
- 时序纪律（motion.html §04）：tap 200ms/20px、双击 260ms/28px、长按 250ms、工具栏自动隐藏 3s（悬停冻结）、OSD 停留 900ms（跳页）/1400ms（换话）、翻页提交阈值 28% 屏宽或 0.5px/ms、预载解码窗口 2 页且延后 200ms、骨架 1.4s、失败 shake 380ms。
- 全局新增 shared 件：`MotionPreset`（时长/曲线常量）+ `Stagger`（逐项 60ms 入场）+ `Shake`（错误反馈）——放 `lib/shared/widgets/motion.dart`。
